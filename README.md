# ☁️ AZURE ACE — AZ-900 Study Companion

**AZURE ACE** is a beginner-friendly study application designed to help learners prepare for the Microsoft Azure Fundamentals (AZ-900) certification exam. It combines interactive lessons, practice quizzes, flashcards, and progress tracking to make learning cloud computing more engaging and accessible.

## ✨ Features

* **📚 Learn:** Explore key Azure concepts through beginner-friendly lessons and practical examples.
* **🎯 Practice:** Test your knowledge with multiple-choice questions and instant feedback.
* **🗂️ Flashcards:** Reinforce your understanding of essential Azure terminology and services.
* **📊 Track Progress:** Monitor quiz performance, completed lessons, and topics that need revision.
* **💾 Save Progress:** Retain study progress using browser local storage.

## 🛠️ Tech Stack

* React 18 with TypeScript for the UI and type safety
* Vite 7 as the build tool and dev server
* Tailwind CSS 3 for styling
* lucide-react for icons
* Browser localStorage for saving study progress (no backend or login required)
